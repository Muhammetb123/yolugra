# Ýolugra

Intercity carpooling for Turkmenistan. Drivers publish trips with free seats and optional stops
on the way; passengers find a ride, request seats for the part of the route they need, and get
the driver's phone number once the driver accepts. One account drives and travels. No payments:
the price per seat is informational and settled between travellers.

The app talks to the Go backend in `../carpool-backend`. Login uses the backend's phone OTP; the
code is generated by the backend and delivered by the Android SMS gateway
(`../sms/delivery_sms_sender`).

## Quick start

```bash
# backend (see DEVELOPMENT_SETUP for details)
cd ../carpool-backend && docker compose up -d postgres && MIGRATE_ON_START=true go run ./cmd/api

# phone over USB
adb reverse tcp:8081 tcp:8081

# app
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run                      # API_BASE_URL defaults to http://127.0.0.1:8081
```
